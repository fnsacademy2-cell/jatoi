How to get your free Firebase credentials (2 minutes)

1. Go to console.firebase.google.com and click Create a project.

2. In the left sidebar, click Build > Firestore Database → click Create Database.

3. Choose Start in test mode (or in Rules tab set allow read, write: if true; so field drivers can save entries without requiring user login).

4. Click the Settings Gear ⚙️ at top left → Project settings → scroll to "Your apps" → click the Web icon </>.

5. Copy the firebaseConfig object and paste it in the Quick Auto-Fill box above!
